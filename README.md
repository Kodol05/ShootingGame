# ShootingGame

C# WinForms로 만드는 세로 스크롤 슈팅 게임 팀 프로젝트입니다. 학습 목적의 팀 과제로,
`Form1.cs`에 기능별 메서드를 미리 나눠두고 각자 구현하는 방식으로 진행했습니다
(김현민, 남준혁, 이교현, 이지원).

## 기획

- 플레이어는 스페이스바로 공격, 아이템을 먹을 때마다 공격 단계가 1→4단계로 강화됩니다
  (정면 탄환 개수 증가 + 좌우 대각선 탄환 추가)
- 잡몹(개미·모기·잠자리)과 보스(지네)가 등장하고, 보스는 패턴 공격(레이저 등)을 씁니다
- `images/`에 배경·캐릭터·탄환·이펙트 스프라이트가 준비되어 있습니다

## 상태

메서드 스켈레톤과 에셋만 있고 실제 구현은 진행 중입니다.

## 실행

Visual Studio에서 `ShootingGame.sln`을 열고 빌드/실행합니다.
